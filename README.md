# bank-customer-churn-prediction
Predicting bank customer churn using Logistic Regression, Random Forest, and Gradient Boosting. Includes EDA, preprocessing, model evaluation, and ROC-AUC scoring.
Dataset
[Kaggle - Bank Customer Churn Prediction](https://www.kaggle.com/datasets/shantanudhakadd/bank-customer-churn-prediction)

## Models Used
- Logistic Regression
- Random Forest
- Gradient Boosting

## How to Run
pip install pandas numpy matplotlib seaborn scikit-learn
python bank_churn_prediction.py

## Evaluation Metric
ROC-AUC Score
